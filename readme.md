# pm4utils - utility scripts for Paper Mario Sticker Star

## `saveedit.py`
A work in progress save editor for Paper Mario Sticker Star.
**IMPORTANT**: Please back up your save file before using this script. Modifying save data may result in crashes or softlocks.

### Requirements
Python3 and tkinter.
On Windows tkinter should be included with python.

### Usage
Download the latest [release](https://github.com/MasterOfRespawn/pm4utils/releases/latest).
Run `python3 saveedit.py` or double click `saveedit.py` if you are on Windows.
NOTE: This script can not create save files, it can only edit them. You will need to load a vaild save file first.
